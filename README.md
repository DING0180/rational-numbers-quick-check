# Rational Numbers Quick Check

An interactive bilingual Quick Check tool for Grade 7 rational-number lessons. It is designed for whole-class teaching, whiteboards, and 16:9 classroom displays.

> **Open the classroom website:** [Rational Numbers Quick Check](https://ding0180.github.io/rational-numbers-quick-check/)

## Project Overview | 项目简介

This project helps teachers quickly generate short, classroom-ready questions for rational-number learning. Students can first check whether they can do a skill, then use a Challenge question to explain, judge, find an error, work backwards, or apply the idea in a new situation.

本项目是面向七年级双语数学课堂的有理数快速检测工具。教师可以快速生成适合课堂大屏展示的题目，用于检查学生是否会做、是否真正理解，以及能否判断、辨错、反推和迁移。

## Features | 主要功能

- **13 lesson modules** covering the complete Rational Numbers Quick Check sequence.
- **Easy and Challenge modes**: Easy checks procedural fluency; Challenge checks mathematical understanding rather than simply adding calculations.
- **Random question generator** with multiple templates for every lesson and difficulty level.
- **Reveal Answer / Next Question** controls for efficient whole-class discussion.
- **Bilingual classroom language**: English is used for main controls, with Chinese lesson support where helpful.
- **KaTeX mathematical typesetting** for clear fractions, expressions, inequalities, and other mathematical notation.
- **Classroom-first layout**: centered safe question area, responsive sizing for long questions, and no horizontal scrolling.
- **Keyboard shortcuts** for quick teacher operation during lessons.
